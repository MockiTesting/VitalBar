# BatteryState · 菜单栏电池状态字形

## 组成（v4.0 / 方案 v2.5）

```
[ 电池外壳 23.50×10.60 + 电极 ]   外壳上下各留 1.20，给插头让出贯穿空间
   插头 6.10×13.00：从图标顶边一直画到底边（上下贯穿外壳，不是装在壳里，仅接电时绘制）
   状态符 6.13×7.00：位于插头右侧
总计 27×13 pt（@1x 27×13 / @2x 54×26 / @3x 81×39），单色黑 + alpha，可作 template
```

**没有电量填充条。** v4.0 起图标是纯线稿：外壳、插头、状态符三个元素，电量只由旁边的百分比文字表达。去掉填充后，插头才能上下贯穿而不被填充条切割，观感也更接近系统里常见的线稿电池。

| 文件 | 插头 | 状态符 | 语义 |
|---|---|---|---|
| `charging` | 有 | 加号 | 已接电源，正在充电 |
| `pause` | 有 | 两条竖条 | 已接电源，充电暂停（到上限 / 保持） |
| `discharging` | 有 | 一条横杠 | 已接电源，但电池在放电 |
| `unplugged` | **无** | 短横（居中） | 纯电池供电 |

**插头是「是否接着电源」的唯一视觉信号**，只由 `ExternalConnected` 决定；状态符再区分接电后的行为。纯电池供电时整块图标没有任何插头痕迹，一眼可辨。

## 几何（pt，左上原点）

| 部件 | 数值 |
|---|---|
| 外壳 | 外沿 23.50×10.60，圆角 3.0，描边 1.10；x 0.70–24.20，y 1.20–11.80 |
| 电极 | 2.10×4.30，圆角 0.85；x 24.30–26.40，y 4.35–8.65（与外壳右描边搭接 0.10） |
| 内壁 | 21.30×8.40（x 1.80–23.10，y 2.30–10.70） |
| 插头 | bbox 5.70×13.00，x 5.74–11.44，**y 0–13.00**（贯穿上下）；引脚 1.80×2.80 ×2（针距 1.05，圆角 0.81）→ 阔身 5.70×4.20（顶角 0.90）→ 凹肩收腰 5.70→2.00（高 2.00，`addCurve`）→ 尾柱 2.00×4.00 |
| 状态符 | 中心 x 16.08（未接电时居中于 12.45），y 6.50；加号 / 减号 6.13×1.80，竖条 1.75×7.00（间距 2.10） |

`BatteryGlyph-gen.swift` 是生成脚本，本目录的 PNG 全部由它产出：

```bash
swiftc -O BatteryGlyph-gen.swift -o /tmp/glyphgen && /tmp/glyphgen   # 输出到 /tmp/batt_v40/
```

验证图（`states.png` 四态 × 浅深底，`pixel-1x.png` 1x 像素 8 倍放大）属于设计产物，与「每一版的实际效果」一起归档，**不随代码仓提交**；需要复现时用上面的命令重新生成。

## 五条绘制规则

1. **外壳按「外沿」定尺寸**：绘制路径要再内缩半个描边（0.55），否则描边会溢出画布、视觉上把图标撑满 13 pt，插头就没有贯穿的余地。
2. **插头上下贯穿，穿越处挖缝**：插头 y 0–13 会穿过外壳的上下描边。只做同色并集，插头会和横线粘成一根，读起来像挂在壳上；沿插头轮廓用 `.clear` 挖掉 0.30 的空隙（`plugHalo`），才看得出是「穿孔而过」。
3. **插头必须有「阔身 + 收腰 + 尾柱」三段**：只画两针加一个圆角方块，1x 下读成插排。定稿比例：引脚 1.80 / 针距 1.05 / 阔身 5.70×4.20 / 收腰 2.00 / 尾柱 2.00×4.00。
4. **圆角不能超过半宽/半高**：`CGPath(roundedRect:cornerWidth:)` 会断言崩溃。短边零件统一取 `min(w, h) × 0.45`。
5. **充电用加号，不用闪电**：13 pt 高度上的闪电会被压成一段折线，加号的四个端点更稳，也更贴合线稿风格。

## 运行时不要用这些 PNG

PNG 只表达状态、不表达电量，仅用于文档、设计稿与降级兜底。app 里请在 `NSImage(size:flipped:)` 里按当前状态现画（几何同上，`flipped` 让 @2x / @3x 自动重绘）。

着色：合成进 `NSStatusItem.button` 时不要依赖 `isTemplate`（模板图与文字混在一张非模板图里会变黑），按 `statusItem.button.effectiveAppearance` 取到的文字色重绘：

```swift
let tinted = img.tinted(with: inkColor)   // 用 sourceAtop 填充 inkColor
```

图标盒固定 **27×13 pt**，插头出现/消失不改变盒宽（`unplugged` 只是不画插头，不是换一张窄图）。
